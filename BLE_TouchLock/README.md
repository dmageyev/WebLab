# BLE Touch Lock

Сенсорний замок на ESP32: відкривається/закривається серво-приводом після дотику до сенсорної кнопки, якщо поруч знайдено Bluetooth-пристрій із пам'яті.

## Технічне завдання

1. **Відкриття.** Короткий дотик до сенсорної кнопки → ESP32 сканує Bluetooth-пристрої поруч. Якщо серед них є пристрій із пам'яті — світлодіод світиться 1 с і серво відкриває замок; інакше — коротке блимання (250 мс).
2. **Закриття.** Дотик з утриманням 2 с → сканування; якщо знайдено відомий пристрій — світлодіод блимає двічі і серво закриває замок; інакше — коротке блимання.
3. **Перший запуск (порожня пам'ять).** ESP32 вмикає Bluetooth, до якого підключаються пристрої, що треба запам'ятати. Після дотику до кнопки світлодіод блимає тричі, пристрої зберігаються в енергонезалежній пам'яті, далі працює алгоритм вище.

## Обладнання

- ESP32 DevKit (вбудований світлодіод на GPIO2)
- Сервопривід (SG90 або подібний)
- Сенсорна кнопка / контактна площадка (дріт або фольга)

## Підключення

| Елемент | Пін ESP32 |
|---|---|
| Сенсорна кнопка | GPIO4 (T0) |
| Серво (сигнал) | GPIO18 |
| Серво (живлення) | 5V / GND |
| Світлодіод | GPIO2 (вбудований) |

## Встановлення

1. Встановіть Arduino IDE та пакет плат **esp32** (Espressif).
2. Через Менеджер бібліотек встановіть **ESP32Servo**.
3. Відкрийте `BLE_TouchLock.ino`, виберіть плату *ESP32 Dev Module* і завантажте скетч.

## Використання

1. Перший запуск: на телефоні в застосунку BLE-сканера (наприклад nRF Connect) підключіться до пристрою **TouchLock**. Підключіть усі потрібні пристрої (до 5).
2. Торкніться кнопки — світлодіод блимне тричі, пристрої збережуться, плата перезапуститься.
3. Короткий дотик — відкрити; дотик 2 с — закрити.
4. Щоб скинути пам'ять, очистіть flash (`Erase All Flash` в Arduino IDE) і прошийте скетч знову.

## Індикація

| Подія | Світлодіод |
|---|---|
| Відкрито | 1 с світиться |
| Закрито | 2 блимання |
| Пристрій не знайдено | 1 блимання, 250 мс |
| Пристрої збережено | 3 блимання |

## Налаштування

Константи на початку скетча: `TOUCH_PIN`, `TOUCH_THRESHOLD`, `SERVO_PIN`, `SERVO_OPEN_ANGLE`, `SERVO_CLOSED_ANGLE`, `HOLD_CLOSE_MS`, `SCAN_SECONDS`, `MAX_DEVICES`.

## Обмеження

- Пристрої ідентифікуються за BLE-адресою. Телефони з випадковою (privacy) адресою можуть її змінювати, тоді пристрій потрібно зареєструвати заново. Для надійності використовуйте BLE-брелки зі статичною адресою.
- Ідентифікація за адресою не є криптографічним захистом; адресу можна підробити. Не використовуйте для критично важливих замків.
- `TOUCH_THRESHOLD` для ESP32-S2/S3 працює інакше (значення зростає при дотику) — потрібна адаптація.
